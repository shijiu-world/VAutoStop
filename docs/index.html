VAutoStop 面板密钥加密

把 MCSManager 面板 api-key 加密成 ENC1: 密文，再填进 config.toml。全程在你自己浏览器里算，不联网、不上传。

1明文 → 密文

复制上面的整串，填到 config.toml 的 apikey：
  • 同一个明文每次加密出来的串都不一样（随机 IV），这是正常的，哪个都能用。
  • 填完保存，服务器里执行 /vautostop reload 即可，不用重启。

2密文 → 明文（排查用）

解不出来只有两种可能：这串不是本页生成的（种子不同），或者复制时被截断了。

3说明

  • 算法：AES-256-GCM，密钥 = SHA-256(内置种子)，输出 = ENC1:base64(IV+密文+校验标签)。
  • 插件端只认「直接写在 config.toml 里」的值：带 ENC1: 前缀才解密，没前缀的明文原样使用。
  • ${env:XXX} 环境变量取回来的值不解密——它本来就不在文件里，没必要再包一层。
  • 这是防「配置文件被随手拷走 / 截图外传 / 丢进仓库」的混淆级保护，不是防逆向：种子编在插件里，拿到 jar 的人理论上能还原。真要严防死守，仍然优先用环境变量。
  • 本页不保存任何输入，刷新即清空；可整页保存到本地离线使用。
